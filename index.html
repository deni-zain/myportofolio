Tentang Saya

Full Stack Developer, Network Engineer, Software Engineer, dan Web Developer yang juga menekuni dunia AI serta analisis data.

Saya Deni Andrian, S.Kom., lulusan S1 Teknik Informatika Universitas Peradaban yang bergerak di persimpangan dua dunia: rekayasa perangkat lunak dan infrastruktur jaringan. Sebagai Full Stack Developer dan Web Developer, saya membangun aplikasi web end-to-end — dari perancangan basis data, REST API, hingga antarmuka yang responsif dan mudah dipakai.

Sebagai Network Engineer dan Software Engineer, saya menangani pemeliharaan server Linux, monitoring NOC, arsitektur client-server, serta troubleshooting jaringan pada penyedia layanan internet. Kombinasi ini membuat saya terbiasa membaca masalah dari dua sisi sekaligus: kode yang berjalan dan infrastruktur yang menopangnya.

Ketertarikan saya kini tumbuh ke arah Artificial Intelligence dan ilmu data: mulai dari pemodelan machine learning dan deep learning, penggalian pengetahuan lewat data mining, hingga penerapan sistem pakar untuk pengambilan keputusan. Bagi saya, data bukan sekadar angka — ia adalah bahan bakar untuk membangun sistem yang benar-benar membantu orang.

Dikuatkan oleh sertifikasi kompetensi nasional BNSP, pelatihan Dicoding dan CodePolitan, saya terus menjaga ritme belajar: menulis kode yang rapi, mendokumentasikan keputusan teknis, dan menyampaikan hasil kerja secara jelas kepada tim maupun pengguna.
